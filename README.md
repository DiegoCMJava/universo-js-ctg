# Universo JS CTG
Este repositorio servirá para tener un plan de estudio organizado al rededor de JavaScript 
Creado por Copilot

---
## 📅 Distribución semanal (mañanas de 3–4 horas)

### **Lunes – Fundamentos + Git**
- **1h**: Fundamentos de programación (algoritmos, estructuras de datos) → *W3Schools*  
- **1h**: Git y GitHub (flujo de ramas, commits, pull requests) → *Commitea*  
- **1h**: Patrones de diseño básicos → *Refactoring Guru*  
- **Opcional (30min)**: Repaso de leyes de UX → *lawsofux*

---

### **Martes – Web base**
- **1h**: HTML → *W3Schools*  
- **1h**: CSS → *W3Schools* + *web.dev*  
- **1h**: JavaScript (DOM, eventos, funciones) → *W3Schools*  
- **Opcional (30min)**: Ejercicios prácticos con mini-proyectos (ej. formulario interactivo)

---

### **Miércoles – Profundización en JS + npm**
- **1h**: JavaScript avanzado (ES6+, promesas, async/await) → *W3Schools*  
- **1h**: npm (instalación, scripts, dependencias locales) → *web.dev*  
- **1h**: TypeScript fundamentos → *W3Schools*  
- **Opcional (30min)**: Práctica integrando npm + TS en un mini-proyecto

---

### **Jueves – Bases de datos + UX**
- **1h**: SQL básico (consultas, joins) → *W3Schools*  
- **1h**: UX aplicado a interfaces → *lawsofux*  
- **1h**: PWA (conceptos, manifest, service workers) → *web.dev*  
- **Opcional (30min)**: Ejemplo práctico: convertir un proyecto sencillo en PWA

---

### **Viernes – Ecosistema moderno**
- **1h**: React fundamentos (componentes, props, estado) → *W3Schools*  
- **1h**: Node.js (módulos, servidor básico) → *W3Schools*  
- **1h**: TailwindCSS (utilidades, responsive design) → *tailwindcss.com*  
- **Opcional (30min)**: Integrar React + Tailwind en un proyecto pequeño

---

### **Sábado – Proyecto integrador**
- **3–4h**: Construir un mini-proyecto que combine lo aprendido:  
  - Frontend con HTML, CSS, JS/TS  
  - Estilos con Tailwind  
  - Backend básico con Node.js  
  - Datos en JSON o SQL  
  - Versionado con Git/GitHub  
  - Aplicar principios UX y PWA  

---

### **Domingo – Repaso ligero**
- Lectura de artículos en *web.dev* o *Refactoring Guru*  
- Revisar repositorios en GitHub para inspirarte  
- Documentar aprendizajes en tu README.md

---

## 🔄 Estrategia de avance
- **Mes 1**: Consolidar grupo 1 y grupo 2 (fundamentos + web base).  
- **Mes 2**: Introducir grupo 3 (React, Node, Tailwind) con proyectos pequeños.  
- **Mes 3**: Integrar todo en proyectos completos, aplicando GitFlow y buenas prácticas.
